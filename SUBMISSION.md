### 3. Long Description (Vollständig)
```
CodI is an Online Vibe Coding Agent powered by AI, enabling autonomous code creation and real-time collaboration with GitHub repositories. It's a browser-based IDE with an intelligent chat interface that can autonomously create, update, and commit code directly to your GitHub repos.

🎯 Key Features:
- GitHub Integration: Connect your repos via Personal Access Token, browse files, and explore code structure
- AI-Powered Chat: Real-time conversation with AI (Mistral-7B via Featherless API) for code assistance
- Autonomous Code Creation: AI automatically creates and updates files in your repo using special syntax patterns
- Auto-Commit: Changes are automatically committed to GitHub with descriptive messages
- Clean UI: Minimal, professional interface inspired by Google AI Studio design
- Real-time File Management: File explorer with folder expansion and file selection

Enterprise Value:
CodI solves real-world friction for developers by eliminating manual code creation workflows. Instead of switching between IDE and chat interfaces, developers can autonomously generate, review, and commit code directly from conversational prompts. This accelerates development cycles and reduces context-switching overhead.

How It Works:
1. Connect your GitHub repo with a Personal Access Token
2. Chat with the AI agent about what you want to build
3. The agent autonomously creates files using special ```create:filename.js syntax
4. Changes are instantly committed to your repo
5. Continue iterating in real-time

Architecture:
- Frontend: React 19 with Vite, React Router, CSS Modules
- AI Backend: Mistral-7B via Featherless API (OpenAI-compatible)
- GitHub Integration: GitHub REST API for repo browsing, file operations, commits
- Deployment: Vercel (serverless, zero-config)
```
